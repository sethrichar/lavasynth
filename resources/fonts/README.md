# Fonts

Embedded in the plugin UI (via `juce_add_binary_data`). Both are licensed under the SIL Open Font License 1.1,
which allows bundling them with software; the license texts sit next to the font files.

- **Share Tech Mono** — labels. © Carrois Type Design. `ShareTechMono-OFL.txt`
